# RecipeBook

## Description
A collection of recipes featuring rich text, image display, and categorized lists.

## Running the Sample
1. Ensure you have the `h5-compiler` installed globally.
2. Build the project using `dotnet build`.
3. Serve the output using `dotnet serve` or any HTTP server inside `bin/Debug/netstandard2.0/h5/`.

## Testing
Please ensure you write Playwright tests to thoroughly test the UI components and interactions.
