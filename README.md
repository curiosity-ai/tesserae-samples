# Tesserae Samples

Welcome to the **Tesserae Samples** repository! This repository contains a collection of simple, interesting, and diverse sample applications built using the [Tesserae UI toolkit](https://github.com/curiosity-ai/tesserae).

Tesserae is a C#-based UI toolkit that compiles to JavaScript using the h5 compiler. These samples are designed to serve as learning resources and reference implementations for developers building single-page applications (SPAs) with Tesserae.

## Samples Gallery

Below is a list of the 20 diverse sample projects included in this repository. Each sample resides in its own directory and comes with its own detailed `README.md` and an initial prompt for an LLM to implement the project.

| Sample Name | Description |
|---|---|
| **TodoApp** | A classic Todo list application demonstrating basic state management, input handling, and list rendering. |
| **WeatherDashboard** | A weather dashboard that fetches and displays weather information, demonstrating async operations and data visualization. |
| **ChatInterface** | A mock real-time chat interface showing scrolling views, message inputs, and layout management. |
| **Calculator** | A simple calculator application focusing on button grids and mathematical operations. |
| **MarkdownEditor** | A side-by-side Markdown editor and previewer, highlighting two-way data binding and live updates. |
| **ExpenseTracker** | An application for logging expenses and income, demonstrating forms and summary views. |
| **AddressBook** | A contact management application showing lists, detailed views, and data filtering/searching. |
| **ImageGallery** | A photo gallery with a masonry layout or grid, demonstrating asset loading and modals/lightboxes. |
| **MusicPlayer** | A mock audio player interface with play/pause controls, progress bars, and track lists. |
| **CalendarApp** | A monthly/weekly calendar view demonstrating complex grid layouts and date handling. |
| **KanbanBoard** | A drag-and-drop task management board showing complex interactivity and column layouts. |
| **RecipeBook** | A collection of recipes featuring rich text, image display, and categorized lists. |
| **PomodoroTimer** | A productivity timer demonstrating intervals, progress indicators, and simple animations. |
| **QuizApp** | A multiple-choice quiz application handling step-by-step state and scoring. |
| **ECommerceStorefront** | A mock online store showing product cards, a shopping cart, and checkout flow concepts. |
| **CurrencyConverter** | A tool to convert between currencies, emphasizing form inputs and basic calculations. |
| **PasswordGenerator** | A utility to generate secure passwords with toggles for length and character types. |
| **DrawingCanvas** | A simple canvas-based drawing app demonstrating integration with HTML5 Canvas in Tesserae. |
| **FileExplorer** | A mock file system explorer demonstrating nested tree views and breadcrumb navigation. |
| **JobBoard** | A job listing board with search and filter capabilities, emphasizing list virtualization or pagination. |
